# 🍔 نظام قالب منيو المطاعم الذكي (Restaurant Menu Template System - V2)

قالب متكامل، فائق السرعة، ومصمم بأعلى معايير **أولوية الجوال (Mobile-First)** لإدارة وعرض قوائم طعام المطاعم والكافيهات. مبني بأحدث تقنيات **Next.js (App Router) + Tailwind CSS + TypeScript + Supabase**.

> **المبدأ الأساسي:**
> 1. قالب ثابت وموحد لا يتغير كوده البرمجي.
> 2. لوحة تحكم كاملة لصاحب المطعم لإدارة الأصناف والأسعار والخصومات ونمط المنيو.
> 3. كل مطعم جديد = ربط بمشروع Supabase عبر متغيرين في `.env.local` فقط، أو تشغيل فوري بدون قاعدة بيانات بالاعتماد على التخزين المحلي وملف `restaurant.ts`.

---

## 📱 1. مميزات أولوية الجوال (Mobile First)

- **شاشات صغيرة (320px - 428px):** تناسق بصري كامل على جميع الهواتف من iPhone SE إلى أحدث أجهزة Android.
- **أزرار مهيأة للمس (Touch-Friendly):** جميع الأزرار وعناصر الإجراءات بارتفاع **44px إلى 52px** لسهولة الضغط بالإصبع.
- **شريط أقسام انسيابي (Sticky Momentum Scroll):** يدعم السحب السلس باللمس ويثبت بأعلى الشاشة عند التمرير.
- **تحميل ذكي وسريع للصور (Lazy Loading):** تقليل استهلاك باقة الإنترنت وتحميل فوري للصور.

---

## 🎛️ 2. سويتش التحكم بنمط المنيو (Menu Mode Toggle)

من لوحة التحكم، يمكن لصاحب المطعم التبديل بين 3 أنماط للمنيو بنقرة زر واحدة:

1. **عرض واستعراض فقط (Display Only):**
   - مخصص داخل الصالة: المنيو يظهر للزبون بدون أي زر طلب أو سلة أو واتساب، فقط لاستعراض الأسعار والوجبات.
2. **طلب فوري بالصنف (Direct WhatsApp):**
   - يظهر زر "طلب سريع" أسفل كل وجبة يفتح محادثة واتساب فورية بالصنف المختار وسعره.
3. **سلة وطلبات متكاملة (Cart & Orders):**
   - نظام سلة تسوق كامل: يتيح للزبون إضافة عدة وجبات، تعديل الكميات، حساب الخصومات، شريط سلة عائم، وإرسال فاتورة مجمعة ومنظمة باسم ورقم الزبون وعنوانه عبر واتساب.

---

## 🛒 3. نظام السلة والفاتورة الذكية عبر واتساب

- **إضافة وتعديل الكميات (+ / -):** بأزرار واضحة وسهلة اللمس.
- **شريط سلة عائم (Floating Cart Bar):** يظهر أسفل الشاشة بمجرد إضافة أصناف مع بيان العدد والإجمالي وزر المعاينة.
- **حساب الخصومات:** دعم الخصومات بنسبة مئوية `%` أو بمبلغ ثابت، وتظهر في السلة والفاتورة.
- **نموذج بيانات الزبون:** الاسم، الجوال، العنوان أو رقم الطاولة، وأي ملاحظات خاصة.
- **رسالة واتساب مجهزة كفاتورة منظمة:**
  ```text
  🧾 طلب جديد من المنيو الإلكتروني
  مطعم: سلطان البرجر
  ---------------------------------------
  👤 بيانات العميل:
  • الاسم: أحمد محمد
  • الهاتف: 0501234567
  • العنوان / الطاولة: طاولة 4 صالة
  ---------------------------------------
  📋 تفاصيل الطلبات:
  ▫️ 1x سلطان سموك برجر (خصم 4 ر.س) 
      = 34 ر.س
  ▫️ 2x بطاطس سلطان المحملة 
      = 48 ر.س
  ---------------------------------------
  💵 المجموع الفرعي: 86 ر.س
  🎉 إجمالي الخصم: -4 ر.س
  💰 المجموع النهائي المطلوب: 82 ر.س
  ---------------------------------------
  📝 ملاحظات: بدون مخلل وزيادة صوص
  ```

## 👑 4. لوحة تحكم صاحب المطعم (`/admin`)

- **رابط الدخول:** `http://localhost:3000/admin/login`
- **بيانات الدخول التجريبية:**
  - اسم المستخدم: `admin`
  - كلمة المرور: `admin123`
- **إمكانيات لوحة التحكم:**
  1. **سويتش النمط والحالة:** تبديل نمط المنيو (عرض فقط / طلب مباشر / سلة)، وتبديل حالة المطعم (مفتوح الآن 🟢 / مغلق 🔴).
  2. **إدارة الأصناف والخصومات:**
     - إضافة صنف جديد مع (الاسم، الوصف، السعر، السعرات، الصورة، القسم، والبادج).
     - سويتش فوري لتعطيل أو تفعيل توفر الصنف (`isAvailable`).
     - إضافة خصم (نسبة مئوية `%` أو مبلغ ثابت) وحسابه تلقائياً.
     - تعديل وحذف الأصناف.
  3. **بيانات المطعم:** تعديل الاسم، الشعار، الغلاف، أرقام الواتساب والهاتف، والعنوان ورابط الخريطة.
  4. **رفع الصور:** رفع صورة مباشرة من الجهاز والحصول على رابط فوري لاستخدامه.

## 🗄️ 5. ربط قاعدة البيانات (Supabase) لأي مطعم جديد

النظام يدعم **السقوط الآمن (Graceful Fallback)**:
- **إذا لم يُربط Supabase:** يعمل الموقع ولوحة التحكم فورياً باستخدام التخزين المحلي وملف `restaurant.ts`.
- **لربط مطعم جديد بقاعدة بيانات حية:**
  1. أنشئ مشروعاً مجانياً في [Supabase](https://supabase.com).
  2. افتح **SQL Editor** والصق محتويات ملف [`supabase-schema.sql`](file:///d:/مطعم/supabase-schema.sql) واضغط **Run**.
  3. أنشئ ملف `.env.local` في مجلد المشروع وضع فيه المفتاحين:
     ```env
     NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
     NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
     ```

## 🎨 6. تخصيص المظهر والهوية: `src/config/theme.css`

لتغيير ألوان أي مطعم جديد: عدل المتغيرات في ملف [`src/config/theme.css`](file:///d:/مطعم/src/config/theme.css):
- `--color-primary`: لون الأزرار والهوية الرئيسية.
- `--color-secondary`: لون الخصومات والتمييز.
- `--color-bg`: خلفية الموقع.
- `--radius-card` و `--radius-btn`: انحناءات البطاقات والأزرار.
